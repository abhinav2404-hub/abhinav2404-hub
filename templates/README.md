# Profile README layout options

The root `README.md` is the live profile design. These alternatives are ready to customize:

- `profile-clean.md` — minimal and easy to scan
- `profile-project-cards.md` — project-first, two-column cards
- `profile-retro.md` — terminal-inspired, with a green retro counter

The animated intro uses Readme Typing SVG. The counter uses GitHub Profile Views Counter; it counts profile views, not unique visitors. Remote widgets may occasionally be unavailable.
