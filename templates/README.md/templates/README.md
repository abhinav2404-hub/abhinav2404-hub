# Profile README layout options

The active profile design is the root `README.md`. Three alternate layouts are included here:

- `layout-clean.md` — minimal and easy to scan
- `layout-project-cards.md` — puts projects first in a two-column card layout
- `layout-retro.md` — terminal-inspired, with a green retro counter

The animated intro uses Readme Typing SVG. The counter uses GitHub Profile Views Counter and counts profile views, not unique visitors. Remote widgets can be temporarily unavailable.
